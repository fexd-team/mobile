# Less Plugin 正则方案 - 边界情况分析

## ✅ 当前可以正确处理的情况

### 1. 基础运算

- ✅ `@width * @scale` → `calc(@width * @scale)`
- ✅ `@height + 10px` → `calc(@height + 10px)`
- ✅ `@a - @b` → `calc(@a - @b)`

### 2. 负号处理

- ✅ `-@var * 2` → `calc(-1 * @var * 2)`
- ✅ `-28px * @scale` → `calc(-1 * 28px * @scale)`
- ✅ `-@padding` → `-@padding` (单个负数不包裹)

### 3. 括号表达式

- ✅ `(@width + @padding) * @scale` → `calc((@width + @padding) * @scale)`
- ✅ `(@height - 10px) / 2` → `calc((@height - 10px) / 2)`

### 4. 多值

- ✅ `@y * @s @x * @s` → `calc(@y * @s) calc(@x * @s)`
- ✅ `@padding 10px @margin * @s` → `@padding 10px calc(@margin * @s)`

### 5. 混合情况

- ✅ `@width * @s solid @color` → `calc(@width * @s) solid @color`

## ⚠️ 可能存在的边界问题

### 1. 嵌套括号的复杂表达式

```less
// 可能有问题
width: (((@a + @b) * @c) / @d) - @e;
```

**问题**：正则 `\([^)]*\)` 不支持嵌套括号匹配 **当前状态**：未测试，可能失败

### 2. 函数调用中的运算

```less
// 可能有问题
rgba(255, 255, 255, @opacity * 0.5)
background: linear-gradient(to right, @color1 @pos1 * 100%, @color2 @pos2 * 100%)
```

**问题**：函数内的运算可能被错误识别 **当前状态**：通过字符串替换 `/(["']).*?\1/g` 部分处理，但不完整

### 3. 多层嵌套的 calc()

```less
// 边界情况
width: calc(calc(@a * @b) + @c);
```

**问题**：可能重复包裹 **当前状态**：有检查 `startsWith('calc(')` 但可能不够

### 4. 特殊运算符组合

```less
// 边界情况
width: @a * -@b; // 乘以负数
height: @a / -2; // 除以负数
margin: -@a - @b; // 负数减法
```

**问题**：负号位置判断可能出错 **当前状态**：部分情况可能失败

### 5. Less 内置函数

```less
// 边界情况
width: percentage(@ratio * @scale);
color: darken(@color, @amount * 10%);
```

**问题**：Less 函数参数中的运算 **当前状态**：可能被错误包裹

### 6. 字符串插值

```less
// 边界情况
content: '@{icon-size} * @{scale}'; // 字符串内
url: 'path/to/image?size=@{size}*2'; // URL 参数
```

**问题**：字符串内的 @ 符号 **当前状态**：有字符串清理，但可能不完整

### 7. 注释中的表达式

```less
// width: @width * @scale;  // 应该跳过
/* 
  示例：@height * @scale
*/
```

**问题**：注释内的表达式 **当前状态**：✅ 已处理（跳过注释行）
