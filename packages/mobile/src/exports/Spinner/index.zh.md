# Spinner 加载指示器 <ImportCost name="Spinner" />

用于页面和区块的加载中状态。

## 属性说明

| 属性  | 说明                                       | 类型   | 默认值 | 提供的值 |
| :---- | :----------------------------------------- | :----- | :----- | :------- |
| delay | 延迟出现时间（防止闪烁），单位为毫秒（ms） | number | 0      | -        |

---

## 样式变量

组件提供了以下 Less 变量，可用于自定义样式：

| 变量名          | 说明           | 默认值               |
| :-------------- | :------------- | :------------------- |
| `@spinner-size` | 加载指示器尺寸 | `32px * @size-scale` |
